        Problem statement

        A directed graph G = (V, E) has a source S, a sink T, a capacity u(e) and a unit cost c(e) on every edge. A flow f assigns a non-negative amount to each edge so that it never exceeds capacity and, at every node except S and T, inflow equals outflow.

        Max flow
  maximise   v
  subject to Σ f(S,j) = v          (value leaving the source)
             Σ f(i,k) − Σ f(k,j) = 0   for every k ≠ S, T
             0 ≤ f(e) ≤ u(e)

Min-cost flow for a required value d
  minimise   Σ c(e) · f(e)
  subject to the same constraints, with v = d

        In resource allocation terms, edges out of S carry supply limits, middle edges are transport or processing capacity, and edges into T carry demand limits.

        Algorithms used

        MethodIdeaTime bound
        Edmonds–KarpAugment along the path with the fewest edges, found by BFS.O(V·E²)
        DinicBuild a BFS level graph, then push blocking flow along level-increasing edges.O(V²·E)
        Ford–Fulkerson (DFS)Augment along any path found by depth-first search.O(E·f*)
        Successive shortest pathsAugment along the cheapest residual path, found by SPFA (queue-based Bellman–Ford).O(f*·V·E)

        f* is the value of the maximum flow. The Ford–Fulkerson bound holds for integer capacities.

        Results the app checks

        • Max-flow min-cut. The value of a maximum flow equals the capacity of a minimum cut. The saturated edges crossing that cut are the system bottleneck.
        • Optimality of min-cost flow. A flow of a given value has minimum cost exactly when the residual graph has no negative-cost cycle. The app runs this test on every min-cost solution.
        • Integrality. With integer capacities, a maximum flow and a min-cost flow with integer value exist with integer flow on every edge.

        How to read the Analysis tab

        • Where to add capacity. For each edge, the gain in maximum flow when its capacity grows by the chosen amount. Only edges on the min cut give a gain.
        • Link failure impact. The loss in maximum flow when one edge is removed. A large loss marks a single point of failure.
        • Cost against flow. Total minimum cost as the delivered flow grows. The slope is the marginal cost of one more unit, and it never decreases.
        • Benchmark. Each algorithm solves the same network. The three max-flow methods must agree on the flow value.
